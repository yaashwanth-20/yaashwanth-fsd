# Full Stack Development (FSD) Observation

This repository contains lab observation experiments and exercises for Full Stack Development.

## Repository Structure

- **`exp 1/`**
  - `exp 1a/` - Basic personal portfolio website created using semantic HTML5.
  - `exp 1b/` - Responsive personal portfolio styled with Bootstrap 5.
- **`exp 2/`** - Student registration form with client-side JavaScript form validation.
- **`exp 3/`** - Node.js HTTP CRUD server implementing `GET`, `POST`, `PUT`, and `DELETE` requests with frontend interaction.
- **`exp 4/`** - Node.js web application handling `GET` and `POST` request parameters using standard HTTP and QueryString modules.
- **`exp 5/`** - Product management CRUD application with Express.js REST API and MongoDB/Mongoose.
- **`exp 6/`** - React personal portfolio application.
